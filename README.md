# My R 유저 설문 결과 사이트

구글 폼 응답 시트를 불러와 10~20대 응답을 분석하고, 레미제라블 팬과 비팬을 나눠 보여주는 정적 사이트입니다.
페이지를 열거나 새로고침할 때마다 시트에서 최신 응답을 다시 불러옵니다.

## 파일
- `index.html`: 화면과 설정(맨 위 `CONFIG`)
- `analysis.js`: 응답 정리, 집계, 해석 문장, 가설 검증, 적용 제안 규칙

## 1. 응답 시트 공개 설정 (둘 중 하나)
**권장: 웹에 게시**
1. 응답 시트에서 `파일 → 공유 → 웹에 게시`
2. 게시할 대상: 응답 탭(예: `설문지 응답 시트1`), 형식: `쉼표로 구분된 값(.csv)` → 게시
3. 나온 주소를 `index.html`의 `PUBLISHED_CSV_URL: ""` 따옴표 안에 붙여넣기

**간단: 링크 공유**
- `공유 → 일반 액세스 → 링크가 있는 모든 사용자 · 뷰어`로 두면 `SHEET_ID`만으로 불러옵니다.

> 두 방법 모두 응답 내용(자유 의견 포함)이 인터넷에 공개됩니다. 자유 의견을 숨기려면 `SHOW_COMMENTS: false`로 바꾸세요.
> 설문에 개인정보(연락처 등)를 받는 문항이 없으므로 그 외 공개 위험은 낮습니다.

## 분석 기준
- **분석 대상**: 나이대 14~16세, 17~19세, 20~23세, 24~26세, 27~29세 (다른 언어는 같은 순서의 출생연도 보기)
- **레미제라블 팬**: Q9에서 '원작 소설(빅토르 위고)을 읽어봤다'(각 언어의 같은 보기)에 체크한 사람
- **국가·권역별**: 설문에 국가 문항이 없어 응답 언어로 구분 (한국어=한국, English=영어권, 日本語=일본, 简体中文=중화권, Español=스페인어권, Français=프랑스어권). 권역: 아시아권(한·일·중), 서구권(영·스·프), 해외 전체(한국어 외). 응답 0명인 줄과 언어가 하나뿐인 권역은 숨김
- 모든 언어의 응답은 한국어 보기로 맞춰서 함께 집계
- 막대 비율 = 각 그룹 안에서 해당 보기를 고른 사람 비율 (복수 선택 문항은 합이 100%를 넘음)
- 설문 문항이나 보기 문구를 바꾸면 `analysis.js`의 `OPT` 목록도 같이 고쳐야 정확히 집계됩니다. 목록에 없는 문구는 '기타 직접 입력'으로 표시됩니다.
